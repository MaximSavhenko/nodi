Repeating the same `delete PROJECT --version VERSION` or `--all` reloads the frozen, checksummed deletion plan and requires the existing typed confirmation again. The journal shares A2's record integrity, private directory handling and OS lock implementation. Before each destructive request it saves intent. Recovery verifies numeric repository ID, original release ID/body/flags, the complete asset snapshot and hashes, tag SHA, and permanent tombstone. Lost successful replies are reconciled from authenticated inventory; an absent release/tag is accepted only after durable intent. Replacement drafts, changed tags/assets/history and corrupt journals are retained for inspection. Completed stale plans cannot issue another DELETE.
